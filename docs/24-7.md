## لماذا خطوتان؟

GitHub يشغّل `schedule` **من الفرع الافتراضي (`main`) فقط**، والفرع الحالي ليس `main`.
وأيضاً لا أستطيع كتابة أسرار المستودع (صلاحياتي محدودة).

لذلك: أنت تدمج الـ PR + تضيف السرّ. المرة الوحيدة.

**https://github.com/3av4/TESTTTT/pull/1** → زر **Merge pull request**

1. افتح: `https://github.com/3av4/TESTTTT/actions/workflows/bot-24-7.yml`

```json

{"level":"info","msg":"[bot] البوت يعمل بنجاح","ctx":{"running":true,"polling":true}}
```

## البيانات (مهم)

كل تشغيل Actions يبدأ بقرص نظيف ⇒ PGlite تُعاد من الصفر.

| الأثر | التفصيل |
|---|---|
| الحسابات | ✅ محفوظة في تلجرام (تُنشأ عند أول `/start`) |
| **الأرصدة** | ⚠️ **تُعاد إلى 1000** مع كل تشغيل جديد |

### للحفظ الدائم — Neon (5 دقائق، مجاني)

1. [neon.tech](https://neon.tech) → New Project (بدون بطاقة)
2. انسخ **Connection string**
3. GitHub → Settings → Secrets → **New secret**
   - الاسم: `DATABASE_URL`
   - القيمة: الرابط + `?sslmode=require`
4. حرّر `.github/workflows/bot-24-7.yml`، وفي خطوة التشغيل بدّل:
   ```yaml
   DATABASE_URL: ""
   ```
   بـ:
   ```yaml
   DATABASE_URL: ${{ secrets.DATABASE_URL }}
   ```
5. ادفع → البيانات تبقى للأبد

## استكشاف الأخطاء

| العَرَض | السبب | الحل |
|---|---|---|
| `❌ السر BOT_TOKEN غير مضبوط` | لم تُضف السر | خطوة 2 |
| `❌ التوكن مرفوض` | توكن خاطئ | `/revoke` جديد |
| `Conflict: can't use getUpdates` | نسخة أخرى تعمل بنفس التوكن | أوقف Render/جهازك |
| البوت لا يرد لكن التشغيل نجح | الويبهوك مسجّل ويعطّل polling | احذفه: `/deleteWebhook` |
| `Network request failed` | GitHub يحجب؟ (نادر) | أعد التشغيل |
| البوت يرد ثم يتوقف فجأة | انتهت الـ 6 ساعات | طبيعي — يعيد تلقائياً |
